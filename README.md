# Клининговое обслуживание офисных зданий

Учебная практика, тема № 53. Кислый Александр Сергеевич, ИКБО-15-24.
Проект содержит процедурную реализацию на Python, объектно-ориентированную
реализацию на Java, физическую модель SQLite и автоматические проверки.
Все входные данные условные. Решение не внедрялось в организацию.

## Требования и запуск

Python 3.10+ и JDK 17+. Проверено на Python 3.12 и 3.10.11, OpenJDK 21, SQLite 3.53.1.
Для запуска достаточно стандартных библиотек. Выполняйте команды из корня
этого проекта (`cleaning-service-practice`), а не из папки с отчётом.

Процедурная версия:

```sh
python3 src/main.py
```

Java на macOS / Linux:

```sh
mkdir -p java/build
javac -encoding UTF-8 -Xlint:all -d java/build java/src/cleaning/*.java
java -cp java/build cleaning.CleaningApp
```

В PowerShell вместо `mkdir -p` используйте:
`New-Item -ItemType Directory -Force java/build`.

Дополнительные аргументы Java: путь к JSON, выходной каталог, год, месяц.

```sh
java -cp java/build cleaning.CleaningApp data/sample_data.json data/java 2026 11
```

Создание демонстрационной базы:

```sh
python3 tools/build_database.py
```

Команда **пересоздаёт** `data/cleaning.sqlite` из учебного JSON и результатов
Python. Если вы вручную изменили базу, предварительно сохраните её копию.
При любом собственном подключении к SQLite включайте `PRAGMA foreign_keys=ON`.
Схема находится в `sql/schema.sql`. Данные добавляются транзакцией;
готовый файл заменяется после успешной проверки целостности.
Java экспортирует CSV и напрямую с SQLite не соединяется.

Проверки (включая сборку Java):

```sh
python3 -m unittest discover -s tests -v
python3 -m compileall -q src tools tests
```

## Правила и ограничения

- ежедневная услуга — по понедельникам–пятницам;
- еженедельная — по средам;
- ежемесячная — первая не исключённая суббота;
- исключённые даты задаются в JSON; календарь не является полным календарём РФ;
- длительности округляются до сотых долей часа до распределения;
- сначала идут более долгие задания, при равной загрузке — меньший ID бригады;
- при разных сменах проверяются следующие бригады, пока не найдена подходящая;
- все назначения одного дня укладываются в смену; учёт переездов не реализован;
- плановая стоимость включает все запланированные выезды, в том числе неназначенные;
- акты и фактическое выполнение работ не формируются автоматически.

Python использует float для стоимости, Java — BigDecimal. Совпадение
подтверждено на тестовых наборах; для произвольных денежных данных следует
перевести Python на Decimal и добавить проверки правил округления.
Входной JSON должен соответствовать примеру; полноценной схемы валидации нет.

## Структура

- `src/` — алгоритмы и запуск Python;
- `java/src/cleaning/` — классы Java и чтение JSON;
- `sql/` — схема из 10 таблиц, ограничения, индексы, представления и триггеры;
- `tools/` — формирование демонстрационной базы;
- `tests/` — 15 проверок алгоритмов, 6 сравнительных и 13 проверок БД;
- `data/` — учебный JSON, Python CSV, Java CSV и SQLite;
- `docs/diagrams/` — исходные схемы прежних этапов и редактируемая UML-схема `Классы_Java.drawio`;
- `docs/evidence/` — фактические результаты запуска и тестов;
- `docs/screenshots/` — снимки редактора draw.io и запуска тестов в VS Code для отчёта.
