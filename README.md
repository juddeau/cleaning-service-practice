# Клининговое обслуживание офисных зданий — учебная практика

Проект по теме №53 «Клининговое обслуживание офисных зданий».

## Структура проекта
- `src/`  — исходный код (реализация алгоритмов на Python и Java на последующих этапах практики)
- `docs/` — документация и отчётные материалы по этапам практики
- `data/` — данные, используемые в работе

## Запуск (этап 3, процедурная реализация на Python)
```
python3 src/main.py
```
Программа читает условные данные из `data/sample_data.json`, считает стоимость
обслуживания объектов за месяц, формирует список заданий на уборку,
распределяет их между бригадами и сохраняет график в `data/schedule_2026_11.csv`.
